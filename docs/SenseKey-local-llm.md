# Первый тест локальной LLM в SenseKey

Сначала запускаем одну модель в Termux и подключаем клавиатуру к ней.
Termux - временный способ проверить качество и задержку. В этой версии SenseKey
содержит клиент, а не встроенный движок и не файл модели. Проверка на телефоне
пользователя ещё нужна; успешная сборка и тестовый HTTP-сервер не измеряют скорость LLM.

## Запуск на телефоне

1. Установить [Termux с F-Droid](https://f-droid.org/en/packages/com.termux/),
   если его ещё нет. Открыть Termux.
2. В Termux основной текстовый экран и есть терминал. Нажать на него, чтобы открыть
   клавиатуру. Вставлять по одной команде и нажимать Enter. Знак `~ $` не вводить -
   это приглашение к следующей команде. Выполнить полное обновление перед установкой
   llama.cpp:

```sh
pkg update
pkg upgrade
pkg install llama-cpp curl
```

При вопросе `[Y/n]` ввести `y` и Enter. Если обновление предлагает заменить
`openssl.cnf`, для этой новой установки выбрать `y`. Дождаться `~ $` после каждой
команды. `pkg update` обновляет список пакетов, `pkg upgrade` - установленные пакеты;
пропуск второго шага может оставить несовместимые curl и OpenSSL.
Проверка перед загрузкой: `curl --version` должна вывести версию без ошибки.

3. Скачать небольшую модель для первого измерения:

```sh
mkdir -p ~/sensekey-models
curl -fL --retry 3 -o ~/sensekey-models/Qwen3-0.6B-Q8_0.gguf \
  https://huggingface.co/Qwen/Qwen3-0.6B-GGUF/resolve/main/Qwen3-0.6B-Q8_0.gguf
```

Это официальный GGUF Qwen3-0.6B в Q8_0, около 639 МБ. Для первого теста выбран
малый размер, а не обещание достаточного качества русского продолжения.
Память работающей модели будет больше размера файла. После измерений можно
сменить модель, не меняя транспорт клавиатуры.

4. Запустить сервер:

```sh
llama-server -m ~/sensekey-models/Qwen3-0.6B-Q8_0.gguf \
  --host 127.0.0.1 --port 8080 --alias sensekey \
  -c 4096 --parallel 1 -t 4 --jinja
```

Сообщения `model loaded` и `listening on http://127.0.0.1:8080` означают готовность.
Сервер не возвращает `~ $`, пока работает; это нормально. Оставить Termux работающим. Сервер слушает
только этот телефон. Для нового запуска достаточно последней команды, повторная
загрузка модели не требуется. Остановка - Ctrl+C в терминале.
Если Android завершает Termux при переходе в мессенджер, проверить ограничения
фоновой работы и экономии батареи для Termux. Не включать GPU-параметры до
измерения базового CPU-режима.

## Подключение клавиатуры

1. Обновить SenseKey установленным APK.
2. Открыть SenseKey DEV → **Продолжения SenseKey** прямо на главном экране.
   Тот же пункт доступен в настройках AI. Стартового видеоролика больше нет.
   Если клавиатура ещё не включена/не выбрана, сверху показан соответствующий
   переход в настройки Android; он не блокирует остальные настройки.
3. Оставить адрес `http://127.0.0.1:8080`; имя модели - пустым для определения
   загруженной модели. При необходимости указать `sensekey`.
4. Нажать **Проверить модель**. Проверка делает только GET `/v1/models`,
   без переписки или черновика. Должно появиться имя модели.
5. Включить **Подсказывать продолжение** и нажать **Сохранить**.

Когда этот режим выключен, остаётся прежнее окно с контекстом. Оно сейчас нужно
для проверки захвата. Когда режим включён, вместо него показывается одна подсказка.
В режиме инкогнито локальные продолжения не запрашиваются.

## Что проверить

1. Открыть текущую переписку WhatsApp. Прокрутить при необходимости предыдущие
   сообщения, затем вернуться к полю ввода.
2. Набрать `Да,` в конце черновика без выделения текста и остановиться.
3. Дождаться подсказки. В строке над ней показано время запроса в миллисекундах.
   Первый ответ может быть медленнее последующих из-за прогрева и обработки контекста.
4. Провести вправо по тексту подсказки примерно на треть ширины клавиатуры.
   Вставляется только продолжение. Нажатие само по себе его не вставляет.
   Если текст не помещается, его можно прокрутить по вертикали.
5. Проверить отмену: продолжить печатать до ответа, передвинуть курсор, выделить
   текст, сменить контакт, закрыть клавиатуру. Старое продолжение не должно вставляться.
6. Остановить сервер и повторить: должна появиться ошибка доступности,
   а не текст ошибки в черновике. Кнопка **Повторить** запускает новый запрос.

Тестовая переписка может содержать вопрос «Сможешь завтра приехать к 11?».
Это пример для проверки, а не зашитый ответ: точный суффикс зависит от модели.
Не отправлять ответ в чат автоматически; сначала прочитать подсказку.

## Ограничения первого подключения

- Триггер пока только `Да,` или `Да, `, одна версия продолжения.
- Хранится до шести просмотренных фрагментов. В запрос идёт конечная часть
  накопленного текста, не более 4 500 UTF-16 символов, плюс до 512 символов черновика
  и короткая инструкция. Это предварительный символьный бюджет, а не точный
  подсчёт токенов. Точный бюджет зависит от токенайзера модели.
- Максимум 64 новых токена; длинный, обрезанный или неожиданный результат
  не предлагается. Запрос отключает thinking для совместимого шаблона.
- Пока окно продолжения открыто, экран повторно читается после пяти секунд
  без нового захвата. Это настоящее чтение Accessibility, а не продление возраста
  старого текста. Навигация, смена контакта и отключение сервиса по-прежнему
  отменяют прежний результат.
- Смена контекста отменяет запрос; результат ещё раз проверяется перед показом
  и перед вставкой. Проверяются поколение беседы, текст, поле, сессия редактора,
  курсор, выделение, приложение и актуальность снимка.
- Клиент принимает только loopback HTTP-адрес, не следует перенаправлениям,
  не использует системный прокси, инструменты AI или облачный резервный сервер.
  Эти ограничения относятся к новому режиму продолжений; остальные унаследованные
  функции AI имеют собственные настройки.
- Модель не читает контакты или постоянный профиль: этих слоёв пока нет.
  Автоматической прокрутки и полного архива переписок пока тоже нет.
- Следующий шаг после измерений - два-три варианта и выбор по веткам.

## Проверено на устройстве

3 октября 2026 пользователь подтвердил установку llama-cpp 0.5.0 в Termux,
скачивание Qwen3-0.6B-Q8_0 и успешные `model loaded` / `listening` на порту 8080.
Первый запрос клавиатуры ещё не проверен: вход в настройки блокировал старый
видеомастер Deskdrop. Новый запуск настроек устраняет этот барьер.
