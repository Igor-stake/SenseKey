SenseKey data handling

Prototype documentation updated 3 October 2026.

Predictive phrases

Sense Context is an Android Accessibility Service you enable in system settings. It reads visible non-editable text from the current application. Recognized WhatsApp conversations can keep up to six captured screens in an in-process cache as you scroll. The cache is not a complete messenger archive or permanent user profile.

When predictions are enabled, SenseKey automatically sends a bounded draft and captured context to your configured loopback llama.cpp server on the same device. It accepts only literal loopback HTTP addresses, does not redirect requests, and has no cloud fallback or tool calls. No messages are sent to your contacts by this feature.

Predictions are disabled for password fields and incognito mode. Context is checked against the current application and editor before a result is shown or inserted.

Manual AI tools

The keyboard also includes inherited tools you trigger manually. Their configured backend may be local or remote, and they can include the separately configured profile. Choose their settings according to the data you intend to send. The profile is not currently used by predictive phrases.

Downloads and inspection

Model downloads connect to the chosen model host; update checks connect to GitHub. Review the source code and current settings for the behavior of the installed build.
