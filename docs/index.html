SenseKey

An experimental keyboard that suggests the next part of your message from conversation context.

Sense Context captures visible text with your permission. A local model running in Termux proposes a continuation, which you can insert by swiping right.

The current prototype has a stable suggestion panel and adjustable keyboard height. It is under active development: relevance, message authors, quotations, and latency still need testing.

Download a successful debug build and follow the model setup guide. Models are downloaded separately.

Profiles, contact-specific style, full chat archives, and call transcripts are future work. The existing profile field serves manual AI tools and is not included in predictive phrase requests.
